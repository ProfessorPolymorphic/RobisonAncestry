About this site

This page is generated from four YAML files — people, families, sources, places — kept in the repository. Every fact cites a source. Where sources disagree, both claims are kept; the first listed is shown on the chart and the rest appear under Conflicts. Each parent→child link carries a confidence level:

documenteda record states the relationship (birth registration, obituary, marriage register)
inferreda chain of reasoning from records (census household adjacency, naming pattern)
statedasserted by a compiled source such as the typed family chart — not yet checked
unverifieda placement guess that needs confirmation

Contributing

Edit the YAML in the repository (the web editor works fine). When a document contradicts what is already recorded, add a second event with its source rather than overwriting. The site rebuilds automatically on every change. Full conventions are in the repository README.
